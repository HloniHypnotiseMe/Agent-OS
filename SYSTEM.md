# SYSTEM.md - Agent-OS System Overview

## Purpose
Agent-OS is a complete modular architecture for an autonomous AI operating system.

It enables:
- Multiple specialized AI agents to collaborate
- Persistent memory and knowledge
- Tool use and automation
- Self-improvement and evolution

## Architecture Principles
- Modularity: Each component is independent but interoperable
- Scalability: Support local and cloud deployments
- Robustness: Handle failures, model changes, async operations
- Security-first: Built-in policies and observability
