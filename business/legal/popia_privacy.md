# POPIA / Privacy Policy for Agent-OS (inspired by C6Group.AiOS real deployment)

## Overview
Agent-OS processes personal and business data only as necessary for autonomous agent operations.

## Data We Collect
- User instructions via JARVIS
- Agent memory and logs (local by default)
- Business data for CEO/Finance/Legal agents

## Principles
- Data stays local by default (no cloud unless configured).
- User controls all memory (can clear via CLI or UI).
- Complies with South African POPIA where applicable.

## User Rights
- Access, correct, or delete your data.
- Export memory.

See full legal/ folder in integrations/C6Group.AiOS for reference templates.

**Note:** This is a template. Consult legal professional for production use.
