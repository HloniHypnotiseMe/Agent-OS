# engineering Skill

## Description
Composable real engineering skills for building robust software (not vibe coding). Includes handoff, verification, teaching, prototyping.

## Inputs
- `task`: engineering task description
- `mode`: "handoff" | "verify" | "teach" | "prototype"

## Execution
Step-by-step with explicit reasoning. Uses issue tracker integration.

## Core Logic
- Triage with labels
- Document decisions
- Handoff cleanly between agents

## Dependencies
- coder agent
- projects

## Integration
Used by Coder, CTO, and any engineering workflow. Follows mattpocock/skills philosophy.
