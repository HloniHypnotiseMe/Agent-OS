# Project Tech Stack

This document outlines the tools and libraries adopted from our latest repository evaluation on 2026-06-04.

## Audio & Music
- **[Demucs](https://github.com/adefossez/demucs)**: High-performance music source separation (drums, bass, vocals, etc.).

## Video & Animation
- **[Recordly](https://github.com/webadderallorg/Recordly)**: Professional screen recording with automatic zooms and cursor smoothing.
- **[SadTalker](https://github.com/OpenTalker/SadTalker)**: AI-driven "talking head" animation from a single image and audio.
- **[LongCat-Video](https://github.com/meituan-longcat/LongCat-Video)**: Foundational model for generating long-form (up to 15m) AI videos.

## AI & LLM Infrastructure
- **[whichllm](https://github.com/Andyyyy64/whichllm)**: CLI for local hardware LLM performance profiling.
- **[gemini-web2api](https://github.com/Sophomoresty/gemini-web2api)**: OpenAI-compatible API wrapper for Google Gemini web models.
- **[ECC](https://github.com/affaan-m/ECC)**: Performance optimization system for AI coding agents.

## Web & Content
- **[html-anything](https://github.com/nexu-io/html-anything)**: Agentic HTML editor for converting raw notes/data into polished web pages.

## Utilities & Resources
- **[Telegram-Drive](https://github.com/caamer20/Telegram-Drive)**: Use Telegram as unlimited cloud storage via API.
- **[FMHY](https://github.com/fmhy/edit)**: Curated index of free tools and media resources.
